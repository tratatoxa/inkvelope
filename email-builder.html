My blocks and templates. Save a block with ★ on its card. The library lasts until you close the tab; save it to a file to use it in other emails.

You can also open an email in Outlook, press ⌘A and ⌘C, then ⌘V in this tab. Images are not imported from the clipboard.

External images and styles are not loaded. For a complete layout, use an email with embedded PNG, JPG or GIF images. File size: up to 20 MB.

Sending

  1. Click “Copy email”.
  2. Create a new Outlook message and paste: ⌘V on Mac, Ctrl+V on Windows.
  3. Send yourself a test email and open it on Mac and Windows before sending it to others.

Make layout changes here and copy the email again. Editing the layout in Outlook can rewrite the HTML.

If copying fails, click the email preview, press ⌘A / Ctrl+A, then ⌘C / Ctrl+C.

Alternative for Outlook for Windows

Download the .htmlfile, then in a new message choose Insert → Attach File → Browse. Choose the file, open the arrow next to Insert, then choose “Insert as Text”. This inserts the HTML without rebuilding it in the editor. Embedded images may not appear; if so, use copy and paste and check the result in Outlook. Images are loaded from files only; server requests are disabled.

Getting started

  1. Open “Blocks” on the left. Build your email from headers, images, headings, text, lists, columns, buttons, dividers and a footer.
  2. Add a block using a button below the list, or drag it into place. Click a block in the preview to open its settings.
  3. Already have an email? Click “Import” in the header and open the file to convert it into blocks.
  4. Under “Appearance” set the fonts, colors and width for the whole email.
  5. Open “Checks” above the preview to find empty links, low-resolution images, missing fonts and Outlook compatibility issues.
  6. Click “Copy email” and paste it into Outlook. See “How to send”.

The builder runs in your browser and sends nothing over the network. Drafts last until the tab closes, so save your work using “Save project (.json)” under Appearance.

Text formatting

  • **bold** — bold text.
  • [link text](https://address) — a link.
  • A blank line starts a new paragraph; a single line break stays in the same paragraph.

Tips

  • Reorder blocks by dragging the ⋮⋮ handle. Drag a new block from the palette into the list.
  • Ctrl+Z / ⌘Z — undo, Ctrl+Shift+Z / ⌘⇧Z or Ctrl+Y — redo.
  • The ▲▼ buttons change spacing by 4 px and other values by 1. Hold a button to keep changing the value.
  • ★ saves a card to My blocks. Save the library to a file to open it in another email.
  • Columns appear side by side in Outlook for Windows and Mac. They stack on narrow screens; check this in Phone view.

Sharp images

Images keep their original bytes and resolution. For an image displayed at 600 px wide, use a source 1200 px wide. PNG works well for screenshots, diagrams and logos; use high-quality JPEG for photos.

Embedding an image does not reduce its quality. If the source is blurry or heavily compressed, replace it with the original. Check the delivered email: the email editor may process images separately.

How the builder works

  • The layout uses tables with a default width of 600 px. Spacing uses table cell padding , supported by both Word (Outlook for Windows) and WebKit (Outlook for Mac).
  • No mso-margin-*, VML or Word lists. List markers and icons use table cells to keep the left edge aligned.
  • Dimensions use pixels. Images have width and heightattributes, and Outlook is set to 96 dpi to keep the layout stable at 125–150% display scaling.
  • Dividers use real lines rather than repeated underscores.
  • Fonts always include a fallback; otherwise Outlook for Windows may use Times New Roman.
  • Russian prepositions and conjunctions stay with the next word using a non-breaking space.
